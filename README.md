# Voice Controlled Smart Wheelchair with GPS Tracking

## Project Description
This project helps people with physical disabilities control a wheelchair using voice commands from an Android smartphone.

## Components
- Arduino Uno
- HC-05 Bluetooth module
- L293D motor driver
- DC motors
- GPS module
- Battery

## Working
1. The user speaks a command into the mobile phone.
2. Bluetooth sends the command to Arduino.
3. Arduino controls the motors.
4. GPS can provide location coordinates for tracking.

## Voice Commands
- Forward
- Backward
- Left
- Right
- Stop

## Software
- Arduino IDE
- Arduino C/C++
